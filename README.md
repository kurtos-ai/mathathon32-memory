# Mathathon 32: memory-constrained first-order optimization

Submission preparation for [problem 32](https://competition.sair.foundation/competitions/mathathon/problems/32).

Authors: Francisco Hernández Iglesias and Jack Mayo. Affiliation: kurtos.ai.

This private repository is under preparation. The original paper and exact-arithmetic computation script are preserved in `inputs/`. Final report, presentation, formalization, build records, and computation results will be added after review. No claim of complete Lean verification is made by this initial checkpoint.

The report must follow the [submission guidelines](https://competition.sair.foundation/competitions/mathathon/participant-rules#content-page-participant-rules-submission-guidelines). Lean and Mathlib must both be pinned to v4.35.0. The repository must be made accessible to the organizers before submission; its visibility remains private at the authors' request.
