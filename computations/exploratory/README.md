These files reconstruct the inline NumPy probes used during proof development. They preserve failed hypothesis checks as well as the corrected coordinate example. They are provenance, not proof certificates. The Lean normalization and projected-register proofs determine which identities are verified.

`nonlinear_qe_parameter_probe.lean` preserves the general nonlinear QE runtime probe. The four closed tests passed and are retained as guarded checks in `Continuation.Semialgebraic.NonlinearExamples`. The additional parameterized quadratic test was stopped after more than one minute of computation without a result, to release the shared compiler. Its displayed expected output is a test expectation, not an observed run. The arbitrary-parameter correctness theorem is proved independently; no practical complexity bound or benchmark-sized execution is claimed. This optional probe is excluded from the default library build.

`projected_syntax_probe.lean` and its log preserve the successful small syntax-generation check: a one-query, one-dimensional projected loss formula with unit slope/radius bounds had first-order binder-tree size 32. This generates the formula without running elimination; the log also checks its principal theorem dependencies.
